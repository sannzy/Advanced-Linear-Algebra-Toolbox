# Linear Algebra Toolbox
An interactive web application for performing linear algebra operations easily and efficiently. Built with **Python** and **Streamlit**.
---

## Why This Project?
The algorithms implemented in this toolbox—particularly Singular Value Decomposition (SVD) and LU Decomposition—serve as the mathematical foundation for advanced data analytics and spatial statistics, including solving Global Regression (OLS) and Geographically Weighted Regression (GWR) models. This tool simplifies those complex calculations into an accessible interface.

## Key Features

This application provides 4 main operational menus:
1. **Matrix Diagonalization**: Checks if a matrix is diagonalizable and computes its eigenvalues and eigenvectors.
2. **LU Decomposition**: Decomposes a matrix into Lower (L) and Upper (U) triangular matrices using Doolittle's method.
3. **Power Method**: Iteratively finds the dominant eigenvalue and its corresponding eigenvector.
4. **Singular Value Decomposition (SVD)**: Decomposes a matrix manually or uses image input to visualize image compression and reconstruction.
